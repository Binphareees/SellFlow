## How to use this file

1. Copy the block in §2 once per interview.
2. Use a participant reference (e.g. `A-001`, `B-002`, `C-003`), never a full name in the committed file.
3. Record exact words in quotes where possible.
4. Mark whether a problem was **unprompted** or **prompted**.
5. Record the commitment ask and the agreed start date exactly.
6. Update the summary table in §1 and the gate counters in §3 the same day.
