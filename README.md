# SellFlow Bootcamp (v2)

SellFlow is a proposed mobile-first PWA for small sellers who take orders through WhatsApp.

**Promise:** Know who still owes you money, and remind them in one tap.

## Status
- Phase 0: Validation. **No code until the Go gate in `VALIDATION_PLAN.md` is met.**
- Kill date: **2026-11-06** (proposed, edit in `STATE.md`). No gate met by then = narrow, pivot, or stop. No extensions without new evidence.
- Budget: $0 for the prototype, within free tiers (verify current limits before launch).

## File map (read in this order)
1. `STATE.md` - current status, decisions, changelog, kill date. **The only file you must update after each milestone.**
2. `VALIDATION_PLAN.md` - how to test demand before building.
3. `MVP_SPEC.md` - the build boundary (only after Go).
4. `TECH_STACK.md` - stack, platform risks, deployment checklist.
5. `ROADMAP.md` - phases and checkboxes.
6. `MONETIZATION_AND_LAUNCH.md` - pricing experiments and launch.
7. `AI_HANDOFF.md` - instructions for any AI or human continuing the work.
8. `templates/` - interview log and pilot tracker. Use these during validation.

## Working principle
Observed behavior beats compliments. Every claim in these docs is a hypothesis until a real seller's behavior confirms it.
